# NidhiOne Frontend

Wealth Management Platform for Indian Ecosystem

## Tech Stack

- React 18
- TypeScript
- Material UI (MUI v5)
- Redux Toolkit
- RTK Query
- React Router v6
- Recharts (for charts)
- Vite

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

Frontend will run on http://localhost:5173

3. Build for production:
```bash
npm run build
```

## Features

- 🔐 Authentication (Login/Register)
- 📊 Dashboard with portfolio overview
- 📈 Asset allocation charts
- 💼 Stocks management with real-time prices
- 🏦 Mutual Funds management with SIP support
- 🎯 Goals tracking
- 📱 Responsive design
